# 学生用の学習メモ・演習記録

このディレクトリには、学生が作成する学習メモと演習記録を格納します。配布教材は [materials](../materials/) を参照します。

## 記述するファイル

GitHub のユーザー名など、自分を識別できる ID をファイル名に使います。教材中の `YOUR_ID` は自分の ID へ置き換えます。

例えば、ID が `student-a` の場合は `docs/lecture/students/student-a.md` に記述します。すでに自分のファイルがある場合は、その内容を残して見出しや演習記録を追記します。他の学生のファイルは、指示がない限り変更しません。

既存の [nattoinf.md](nattoinf.md) も、このディレクトリで引き続き管理します。

## 記録する内容

- 学んだことを、自分の言葉で記述します。
- 実行したコマンド、観察した値、予想と実際の結果を記録します。
- 分からなかったことや、追加で確認したいことを記録します。
- パスワード、Cookie、トークン、API キーなどの秘密情報は記述しません。

Git 操作はリポジトリルートで行います。自分の記録をステージする場合は、例えば次のように指定します。

```bash
git add docs/lecture/students/student-a.md
```
