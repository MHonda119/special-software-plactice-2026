# Git・GitHub学習メモ

## Git
- Gitで管理できること：誰がいつどのように編集したか
- git statusの用途：現在のブランチや、ステージング済み・未ステージングの変更、未追跡ファイルなど、Gitの管理状態を確認する。
- git addの用途：ワーキングディレクトリの変更をステージングエリアに登録する。
- git commitの用途：ステージングエリアにある変更をもとにコミットを作成し、ローカルリポジトリに記録する。

## GitHub
- Gitとの違い：Gitはソースコードなどの変更履歴を管理するバージョン管理システム。GitHubはGitリポジトリをオンライン上で管理・共有し、複数の開発者による共同開発を支援するプラットフォーム。
- Issueの役割：バグや改善点、今後開発する機能などを記録・管理し、議論するための機能。
- PRの役割：ローカルで開発されたものをリモートリポジトリのブランチに反映させた上で、mainへ反映させるためのレビュー依頼。

## gh
- gh issue view [issue番号]　--repo [repogitory] : issueのタイトルと本文、その他情報を表示する。
