# Git・GitHub学習メモ

## Git
- Gitで管理できること：ファイルの変更履歴の記録や管理ができる。
- git statusの用途：ファイルの変更や、コミット対象としてステージングされている内容を確認する。
- git addの用途：次のコミットに含める変更をステージに載せる。
- git commitの用途：ステージングした変更を説明とともに履歴へ記録する。

## GitHub
- Gitとの違い：Gitは手元のファイルと変更履歴を管理するツール。GitHubはGitリポジトリを共有し、IssueやPRを使って共同作業するサービス
- Issueの役割：やることや困っていること、完了条件を記録する
- PRの役割：ブランチの変更をレビューしてもらい、リポジトリに取り込むための提案をする

## gh
- `gh pr diff`はPRの変更差分を確認する。
- gitは手元の変更履歴を操作し、ghはGitHub上のIssueやPRなどを操作する。
