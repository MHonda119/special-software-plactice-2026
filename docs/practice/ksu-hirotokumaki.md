# Git・GitHub学習メモ

## Git
- Gitで管理できること：ファイルの変更履歴を管理できる。
- git statusの用途：現在のブランチや、変更・ステージングの状態を確認する。
- git addの用途：次のコミットに含める変更をステージングする。
- git commitの用途：ステージングした変更をローカルリポジトリの履歴として記録する。

## GitHub
- Gitとの違い：Gitはローカルで変更履歴を管理する仕組みで、GitHubはGitのリポジトリを共有し、共同開発するためのサービス。
- Issueの役割：やることや問題点、完了条件を記録する。
- PRの役割：作業ブランチの変更をmainなどへ取り込んでもらうための提案・レビュー依頼。

## gh
- `gh issue view`：GitHub上のIssueをターミナルから確認できる。
- Gitはローカルの履歴を操作し、ghはGitHub上のIssueやPRを操作する。

## MCP
- GitHub MCPでリポジトリ名とIssue番号を指定してIssue #4を取得し、目的・作業内容・完了条件を確認した。
- GitHubの画面と照合して内容が一致することを確認できた。画面を開かなくてもIssueを取得でき、画面表示との一致も確かめられた。

## Skills
- Skillsは、繰り返す作業手順を保存し、必要なときに再利用できる。
- 今回は学習メモ整理用のSkillを使い、対象ファイルと追記する内容を指定して、Skillsの節に学んだことと使い方を記録した。
