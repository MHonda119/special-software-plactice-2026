
# Git・GitHub学習メモ

## 1. GitとGitHubの違い

Gitは、ファイルの変更履歴を管理するためのバージョン管理システムである。

GitHubは、Gitで管理しているコードをオンラインで共有し、複数人で共同開発するためのサービスである。

## 2. 基本的なGitコマンド

- `git clone`：GitHub上のリポジトリをローカルに複製する。
- `git status`：ファイルの変更状態を確認する。
- `git pull`：リモートリポジトリの変更を取得して統合する。
- `git switch -c`：新しいブランチを作成し、そのブランチに切り替える。
- `git add`：コミット対象の変更をステージングする。
- `git commit`：ステージングした変更を履歴として記録する。
- `git push`：ローカルのコミットをリモートリポジトリに送信する。

## 3. GitHub CLI（gh）で学んだこと

GitHub CLIを使うと、ターミナルからGitHubの操作ができる。

今回、`gh auth login` で認証し、`gh auth status` でログイン状態を確認した。
