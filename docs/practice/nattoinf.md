# Git・GitHub学習メモ

## Git
- Gitで管理できること：バージョン管理システム。ファイルの変更履歴などを記録する。サーバさえあればGithubを介する必要がない。
- git statusの用途：現在のリポジトリの状態を確認する。
- git addの用途：変更したファイルをステージングエリアへ移動する。
- git commitの用途：ステージングされた内容を記録する。

## GitHub
- Gitとの違い：Gitはバージョン管理システムのこと。Githubはソフトウェア開発用のプラットフォームのこと。
- Issueの役割：タスク管理やバグ報告などをチーム内で共有する掲示板。
- PRの役割：自分が変更を加えたコードを、確認してメインに読み込むことを要求する。

## gh
- `gh` は GitHub CLI（コマンドラインインターフェース）で、ターミナルから GitHub の機能を利用するためのツール。
- GitHub に認証して使うと、Issue や Pull Request の確認・作成・コメント、差分や CI の状態の確認などをコマンドで行える。
- Git の基本操作（変更の記録やブランチの操作）を行う `git` と連携し、リポジトリでの作業をターミナル内で進められる。
