# Git・GitHub学習メモ

## Git
- Gitで管理できること：ファイルの変更履歴。
- git statusの用途：今の状態を確認する。
- git addの用途：編集した変更のうち、次のコミットに含めるものを選ぶ。
- git commitの用途：addした変更を、メッセージを付けて履歴に記録する。

## GitHub
- Gitとの違い：Gitは自分のPCで動く変更履歴の管理ツール。GitHubはGitのリポジトリをネット上に置いて、共有やバックアップ、共同作業ができるサービス。
- Issueの役割：やること、バグ、相談を登録する場所。
- PRの役割：ブランチで行った変更を「mainに取り込んでください」と提出する。

## gh
- gh issue comment：ターミナルからIssueにコメントを投稿する。ブラウザを開かずに進捗を報告できた。
- gitとghの違い：gitは自分のPCにある変更履歴を操作し、ghはGitHub上のIssueやPRを操作する。
